Reinforcement LearningMulti-Objective Optimization2026

A Sequential Decision Framework for Geosteering

A closed-loop framework that keeps the subsurface model current as new logging-while-drilling data arrives, and hands trajectory selection to an explicit decision engine. I implemented and compared NSGA-II against a tabular Q-learning agent on a synthetic case with known ground truth and a real case study — well F-11B, Hugin Formation, Volve Field. Both methods placed the well within a percentage point of the field's own porosity exposure at first production.

Open-source, end-to-end pipeline using Sentinel-2 imagery and a lightweight CNN to detect artisanal mining sites across Africa, with weekly monitoring via Google Earth Engine and a Streamlit dashboard for regulators and NGOs.

Data Assimilation2023

A data assimilation tool coupling Sequential Gaussian Simulation with an EnKF to history-match reservoir simulation models against observational data, supporting uncertainty and risk management.
